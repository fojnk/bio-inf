# Домашнее задание 6: Молекулярный докинг

## Задание

Выполнить молекулярный докинг препарата **Симвастатин** на мишень **HMG-CoA редуктаза** (PDB ID: 1DQA).

## Исходные данные

- **Лиганд**: Симвастатин
- **SMILES лиганда**: `[H][C@]12[C@H](C[C@@H](C)C=C1C=C[C@H](C)[C@@H]2CC[C@@H]1C[C@@H](O)CC(=O)O1)OC(=O)C(C)(C)CC`
- **Таргет**: HMG-CoA редуктаза
- **PDB ID таргета**: 1DQA


### 1. Информация о препарате

#### a. Действующее вещество

**Симвастатин** (Simvastatin) — действующее вещество одноименного препарата. Химическое название: (1S,3R,7S,8S,8aR)-8-{2-[(2R,4R)-4-гидрокси-6-оксооксанов-2-ил]этил}-3,7-диметил-1,2,3,7,8,8a-гексагидронафтален-1-ил (2,2-диметилбутаноат).

#### b. Область применения

Симвастатин применяется для:
- Снижения уровня общего холестерина в крови
- Снижения уровня липопротеинов низкой плотности (ЛПНП, "плохой" холестерин)
- Снижения уровня триглицеридов
- Повышения уровня липопротеинов высокой плотности (ЛПВП, "хороший" холестерин)
- Лечения гиперхолестеринемии (повышенного уровня холестерина)
- Профилактики сердечно-сосудистых заболеваний (инфаркт миокарда, инсульт)
- Вторичной профилактики у пациентов с ишемической болезнью сердца

#### c. Молекулярный механизм действия

Симвастатин является **пролекарством** (неактивной формой), которое в организме человека подвергается гидролизу с образованием активной β-гидроксикислотной формы.

Активная форма симвастатина **конкурентно ингибирует фермент ГМГ-КоА редуктазу** (3-гидрокси-3-метилглутарил-коэнзим А редуктазу, HMG-CoA reductase). Этот фермент катализирует превращение 3-гидрокси-3-метилглутарил-коэнзима А (HMG-CoA) в мевалоновую кислоту — ключевой и лимитирующий этап в биосинтезе холестерина в печени.

Ингибирование HMG-CoA редуктазы приводит к:
1. Снижению синтеза холестерина в печени
2. Увеличению экспрессии рецепторов ЛПНП на поверхности гепатоцитов
3. Повышению захвата и катаболизма ЛПНП из кровотока
4. Снижению уровня холестерина в плазме крови

Симвастатин структурно похож на промежуточный продукт реакции HMG-CoA → мевалоновая кислота, что позволяет ему эффективно связываться с активным центром фермента и блокировать его активность.

#### Химические данные

- **SMILES**: `[H][C@]12[C@H](C[C@@H](C)C=C1C=C[C@H](C)[C@@H]2CC[C@@H]1C[C@@H](O)CC(=O)O1)OC(=O)C(C)(C)CC`
- **Молекулярная формула**: C₂₅H₃₈O₅
- **Молекулярная масса**: 418.57 г/моль

#### Целевой белок для докинга

- **Название**: HMG-CoA редуктаза (3-гидрокси-3-метилглутарил-коэнзим А редуктаза)
- **PDB ID**: 1DQA
- **Ссылка**: https://www.rcsb.org/structure/1DQA



### 2. Запуск ноутбука с докингом

Ноутбук `basic_molecular_docking.ipynb` был успешно выполнен. В процессе работы были выполнены следующие этапы:

1. **Подготовка окружения**: Установлены все необходимые библиотеки (AutoDock Vina, Meeko, OpenBabel, PLIP, Py3Dmol, RDKit, spyrmsd)
2. **Подготовка белка**: 
   - Загружена структура 1DQA из RCSB PDB
   - Извлечены субъединицы белка (цепи A, B, C, D)
   - Выбрана цепь A для докинга (`1DQA_prot_A.pdb`)
   - Создан файл `1DQA_prot_A.pdbqt` с параметрами Gasteiger
3. **Подготовка лиганда**:
   - Создана 3D структура симвастатина из SMILES нотации
   - Выполнена энергетическая минимизация с использованием силового поля UFF
   - Создан файл `simvastatin.pdbqt` для докинга

### 5. Анализ результатов докинга

#### 5.1. Параметры докинга

Докинг был выполнен с использованием следующих параметров:
- **Программа**: AutoDock Vina 1.2.5
- **Таргет**: HMG-CoA редуктаза (1DQA, цепь A)
- **Лиганд**: Симвастатин
- **Метод определения grid box**: LaBOX (на основе нативного лиганда)
- **Exhaustiveness**: 16 (по умолчанию)

#### 5.2. Ожидаемые результаты

AutoDock Vina генерирует несколько конформаций лиганда с оценками связывания (binding affinity) в ккал/моль. Более отрицательные значения указывают на более сильное связывание. Типичные значения для хороших ингибиторов HMG-CoA редуктазы находятся в диапазоне от -8 до -12 ккал/моль.

#### 5.3. Анализ взаимодействий

Для анализа взаимодействий между симвастатином и HMG-CoA редуктазой использовался инструмент PLIP (Protein-Ligand Interaction Profiler). PLIP определяет следующие типы взаимодействий:
- **Гидрофобные взаимодействия** (HYDROPHOBIC)
- **Водородные связи** (HBOND)
- **Водяные мостики** (WATERBRIDGE)
- **Солевые мостики** (SALTBRIDGE)
- **π-стэкинг** (PISTACKING)
- **π-катионные взаимодействия** (PICATION)
- **Галогенные связи** (HALOGEN)
- **Металлические координации** (METAL)
